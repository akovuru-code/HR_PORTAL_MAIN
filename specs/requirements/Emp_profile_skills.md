# Employee Profile Resume & Skills - EARS Requirements

## Overview
This document specifies the requirements for the Employee Profile Resume & Skills screen using the EARS (Easy Approach to Requirements Syntax) format, covering frontend, backend, and database. The UI and styling must match the attached screenshot.

## 1. Resume/CV Management
- When an employee accesses the Resume & Skills screen, the system shall display a section for uploading and viewing Resume/CV files.
- The system shall allow the employee to upload a Resume/CV file if not already uploaded.
- When a Resume/CV is uploaded and saved, the system shall prevent the employee from overriding or replacing the file.
- If the employee wishes to override or update the Resume/CV after it is saved, the system shall require the employee to submit a request for admin permission.
- When the admin grants permission, the system shall allow the employee to upload a new version of the Resume/CV.
- The system shall display the name of the uploaded Resume/CV file and a preview or summary of its content.

## 2. Cover Letter Management
- The system shall display a section for uploading and viewing Cover Letter files.
- The system shall allow the employee to upload a Cover Letter file if not already uploaded.
- When a Cover Letter is uploaded and saved, the system shall prevent the employee from overriding or replacing the file.
- If the employee wishes to override or update the Cover Letter after it is saved, the system shall require the employee to submit a request for admin permission.
- When the admin grants permission, the system shall allow the employee to upload a new version of the Cover Letter.
- The system shall display the name of the uploaded Cover Letter file and a preview or summary of its content.

## 3. Skills Management
- The system shall display a section for the employee to enter and edit their skills in a text area.
- The system shall allow the employee to save their skills information.

## 4. Resume/CV Filtering
- The system shall provide a filter section for Resume/CV, allowing the employee to select a category type and upload a file for filtering.
- The system shall display the filtered result after the employee clicks the Result button.

## 5. Permissions and Restrictions
- The system shall prevent employees from overriding or replacing uploaded Resume/CV or Cover Letter files unless admin permission is granted.
- The system shall provide a mechanism for employees to request override permission from the admin.
- The system shall notify the employee when permission is granted or denied.

## 6. Usability
- The system shall provide clear feedback for successful uploads, saves, and permission requests.
- The system shall display all fields and actions in a user-friendly and accessible manner.
- The UI and styling shall match the attached screenshot, including layout, icons, and section separation.

## 7. Modifications & Improvements
- The system should allow multiple Resume/CV and Cover Letter uploads, with the ability to select the active one.
- The system should support drag-and-drop file upload for better usability.
- The system should provide a skills suggestion feature based on the uploaded Resume/CV content.
